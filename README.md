# SSH Term — SSH-клиент для Android

SSH-клиент, в котором удобно набирать команды, копировать вывод и вставлять текст.

**Автор:** Ага Умудханов
**Разработано с помощью** [Claude Code](https://claude.com/claude-code).

**Скачать APK:** [dist/ssh-term-1.1.apk](dist/ssh-term-1.1.apk) — версия 1.1, Android 8.0+.

## Возможности

**Ввод команд**
- Отдельная строка ввода внизу: команду можно спокойно набрать и отредактировать обычной клавиатурой
  (с автоисправлением или без него), а потом отправить кнопкой ➤ или клавишей Enter.
  Долгое нажатие на ➤ вставляет текст без Enter.
- Многострочные команды и скрипты вставляются целиком (через bracketed paste, если сервер его поддерживает).
- История команд отдельно для каждого сервера (кнопка 🕘): нажатие подставляет команду, долгое нажатие
  открывает меню «выполнить / копировать / в сниппеты / удалить».
- Сниппеты — панель быстрых команд над клавиатурой. Сниппет либо выполняется сразу, либо подставляется
  в строку для правки. Долгое нажатие на сниппет открывает редактирование, «+» добавляет новый.
- Режим прямого ввода (кнопка ⌨) для vim, nano, htop, mc, less: клавиши идут прямо в терминал.
- Дополнительные клавиши: ESC, TAB, залипающие CTRL/ALT, стрелки (с автоповтором), Home/End, PgUp/PgDn,
  ^C, ^D, ^Z, ^L, `/ | - ~`. CTRL работает и с русской раскладкой.
- Поддержка аппаратной клавиатуры, включая Ctrl+Shift+V.

**Копирование и вставка**
- Долгое нажатие на текст выделяет слово, маркеры тянутся, панель «Копировать / Выделить всё / Вставить».
- Двойное нажатие на слово в выводе (имя файла, путь, id) вставляет его в строку команды.
- «Копировать вывод последней команды» — одной кнопкой в панели сверху.
- «Выделить текст…» открывает весь вывод как обычный текст с системным выделением.
- «Копировать экран» и «Копировать всё».
- Кнопка вставки: в строку команды; долгое нажатие — сразу в терминал.

**Терминал**
- Эмуляция xterm-256color: 256 цветов и truecolor, альтернативный экран, области прокрутки, символы
  псевдографики, широкие символы (CJK/emoji), UTF-8 и кириллица.
- История прокрутки (до 20 000 строк), прокрутка жестом, кнопка «вниз».
- В полноэкранных программах свайп прокручивает саму программу (колесо мыши или стрелки).
- Масштаб шрифта щипком, 4 цветовые схемы.

**Подключения**
- Список серверов, быстрое подключение строкой `user@host:port`.
- Вход по паролю (в том числе keyboard-interactive) и по ключам: Ed25519, RSA, ECDSA, ключи с
  парольной фразой; форматы OpenSSH, PEM и PuTTY.
- Создание ключей Ed25519 / RSA 4096 на телефоне, копирование и отправка публичного ключа.
- Проверка ключа сервера: при первом подключении показывается отпечаток, при смене ключа — предупреждение.
- Пароли, приватные ключи и фразы хранятся зашифрованными (AES-GCM, ключ в Android Keystore).
- Несколько сессий одновременно; соединения держатся в фоне (уведомление с кнопкой «Отключить все»).
- Команда, выполняемая после входа, keep-alive и переподключение одним нажатием.

Требуется Android 8.0 (API 26) или новее.

## Сборка

### Без Android Studio (`sdkbuild/`)

Сборка напрямую через инструменты Android SDK (aapt2, R8, zipalign, apksigner) — без Android Gradle
Plugin и без репозитория Google Maven; все библиотеки берутся из Maven Central.
Нужны JDK 17+ и Android SDK с `platforms;android-36` и любыми `build-tools`.

```sh
export ANDROID_HOME=/path/to/android-sdk
./gradlew -p sdkbuild test assembleApk
# APK: sdkbuild/build/outputs/ssh-term-<версия>.apk
```

APK подписывается ключом `sdkbuild/keystore/local-release.jks` (создаётся автоматически при первой
сборке, в git не попадает). Чтобы подписать своим ключом:

```sh
./gradlew -p sdkbuild assembleApk \
  -Psigning.storeFile=/path/release.jks -Psigning.storePassword=... \
  -Psigning.keyAlias=... -Psigning.keyPassword=...
```

Обновление поверх установленного приложения возможно только с той же подписью.

### Android Studio

Корневой проект — обычный проект Android Gradle Plugin (`app/build.gradle.kts`), его можно открыть в
Android Studio. Версии и идентификатор приложения общие для обеих сборок: `app/version.properties`.

## Тесты

- `./gradlew -p sdkbuild test` — юнит-тесты эмулятора терминала (escape-последовательности,
  прокрутка, ресайз, UTF-8, широкие символы, фазз-тест).

## Структура

```
app/src/main/java/com/one4zero/sshterm/
  terminal/  эмулятор VT100/xterm, отрисовка (TerminalView), кодирование клавиш
  ssh/       подключение (JSch), ключи, сессии, фоновый сервис
  data/      серверы, ключи, сниппеты, история, known hosts, шифрование секретов
  ui/        экраны приложения
sdkbuild/    сборка APK без Android Gradle Plugin
```

SSH-протокол реализован библиотекой [JSch (mwiede)](https://github.com/mwiede/jsch) с BouncyCastle
(Ed25519, curve25519, chacha20-poly1305, ML-KEM).
