## Full description (max 4000)
ClipShell is a free SSH client designed for working with AI assistants. Copy a command together with its output in one tap, paste it into any AI chat, and paste the suggested commands back into the terminal — without the Markdown clutter.

COMPLETELY FREE
• No ads, subscriptions, in-app purchases or sign-up.
• The app does not collect or send any of your data.

BUILT FOR AI WORKFLOWS
• "Copy for AI" — the last command and its output as a ready-to-paste code block.
• "Send to AI" — the same, straight to your assistant app via the share sheet.
• Copy any selected output as a code block.
• Smart paste strips ``` fences and $ prompts from commands copied from AI answers.
• Safety first: a pasted command lands in the input line, so you review it before it runs.

COMFORTABLE COMMAND INPUT
• A separate input line with per-server history and quick-command snippets.
• Double-tap a word in the output to insert it into the command line.
• Direct keyboard mode for vim, nano, htop, mc, plus extra keys (Ctrl, Alt, Esc, Tab, arrows).

A REAL TERMINAL
• xterm-256color emulation with truecolor, line drawing, UTF-8.
• Text selection, scrollback, pinch to zoom, several sessions, background connections.

SECURITY
• Password and key authentication (Ed25519, RSA, ECDSA, passphrase-protected keys).
• On-device key generation, host key verification, secrets encrypted with the Android Keystore.
