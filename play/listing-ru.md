# Описание для Google Play — русский (основной язык)

## Название (до 30 символов)
ClipShell: SSH для работы с ИИ

## Краткое описание (до 80 символов)
Бесплатный SSH-клиент для работы с ИИ: копируйте вывод, вставляйте команды

## Полное описание (до 4000 символов)
ClipShell — бесплатный SSH-клиент, созданный специально для работы с ИИ-ассистентами. Управляете сервером вместе с чат-ботом? Скопируйте команду вместе с её выводом одной кнопкой, вставьте в чат, а ответ ИИ вставьте обратно в терминал — без лишней разметки.

ПОЛНОСТЬЮ БЕСПЛАТНО
• Без рекламы, подписок, встроенных покупок и регистрации.
• Приложение не собирает и никуда не отправляет ваши данные.

СДЕЛАНО ДЛЯ РАБОТЫ С ИИ
• «Копировать для ИИ» — последняя команда и её вывод в виде блока кода, готового для вставки в любой ИИ-чат.
• «Отправить в ИИ» — то же самое сразу в приложение ассистента через меню «Поделиться».
• Выделите любой фрагмент вывода и скопируйте его как блок кода кнопкой «Для ИИ».
• Умная вставка: из скопированного ответа ИИ автоматически убираются обрамление ``` и символы $ перед командами.
• Безопасность: команда из чата сначала попадает в строку ввода — вы видите и можете поправить её перед выполнением.

УДОБНЫЙ ВВОД КОМАНД
• Отдельная строка ввода: набирайте и редактируйте команды обычной клавиатурой, отправляйте одним касанием.
• История команд для каждого сервера и сниппеты — быстрые команды над клавиатурой.
• Двойное нажатие на слово в выводе (путь, имя файла, id) вставляет его в строку команды.
• Прямой ввод для vim, nano, htop, mc; дополнительные клавиши Ctrl, Alt, Esc, Tab, стрелки, ^C, ^D, ^Z.

ПОЛНОЦЕННЫЙ ТЕРМИНАЛ
• Эмуляция xterm-256color: 256 цветов и truecolor, псевдографика, UTF-8 и кириллица.
• Выделение текста с маркерами, копирование экрана или всей истории, прокрутка и масштаб щипком.
• Несколько сессий одновременно; соединения не обрываются, пока приложение свёрнуто.

БЕЗОПАСНОСТЬ
• Вход по паролю или SSH-ключу: Ed25519, RSA, ECDSA, ключи с парольной фразой (форматы OpenSSH, PEM, PuTTY).
• Создание ключей на телефоне и отправка публичного ключа в одно касание.
• Проверка ключа сервера с предупреждением при его изменении.
• Пароли и ключи хранятся зашифрованными с помощью Android Keystore.
• Понятные сообщения об ошибках: например, если сервер пускает только по ключу, приложение подскажет, что делать.
