## 1. Аккаунт разработчика

1. Зарегистрируйтесь на https://play.google.com/console. Это разовый платёж $25 и проверка личности.
2. **Важно для личных аккаунтов, созданных после 13 ноября 2023:** перед публикацией для всех нужно
   провести **закрытое тестирование: минимум 12 тестировщиков, 14 дней подряд**. Без этого кнопка
   «Рабочая версия» (production) будет недоступна. Тестировщиков добавляют по Google-почте;
   подойдут друзья и знакомые с Android.

## 2. Создание приложения

«Создать приложение»:
- Название: `ClipShell: SSH для работы с ИИ`
- Язык по умолчанию: русский
- Тип: приложение, **бесплатное**. Поменять бесплатное приложение на платное потом нельзя,
  и это как раз соответствует «полностью бесплатно».
- Отметьте согласие с правилами.

## 3. Подпись приложения

Оставьте **Play App Signing** (вариант по умолчанию). Google хранит ключ подписи приложения, а вы
подписываете загружаемый AAB **ключом загрузки** (`upload-key.jks`).

- Храните `upload-key.jks` и пароль в надёжном месте, например в облаке и на флешке. Без него нельзя
  выпускать обновления. Если ключ потерялся, его можно сбросить через поддержку Play, но это занимает время.
- APK, который вы ставили вручную, подписан другим ключом. Перед установкой из Play удалите тестовую
  версию. Сохранённые серверы и ключи при этом удалятся, а публичный ключ на сервере нужно будет заменить.

## 4. Страница в магазине («Основная информация о приложении»)

- Краткое и полное описание: из `listing-ru.md`.
- Значок: `graphics/icon-512.png`.
- Баннер: `graphics/feature-graphic.png`.
- **Скриншоты телефона: минимум 2, лучше 4–6.** Снимите их на своём телефоне (кнопки питания и

## 6. Декларация фоновой службы (FOREGROUND_SERVICE_SPECIAL_USE)

Play попросит описать, зачем нужна служба типа `specialUse`, и прислать ссылку на короткое видео.

**Видео (30–60 секунд, можно «доступ по ссылке» на YouTube):** подключитесь к серверу, запустите
команду, сверните приложение и покажите уведомление «1 активная сессия», затем вернитесь: сессия
жива. Ещё покажите кнопку «Отключить все» в уведомлении.

**Текст описания (на английском, так быстрее проходит проверку):**

> ClipShell is an SSH terminal. The foreground service keeps the user's interactive SSH sessions
> (encrypted network connections to the user's own servers) open while the app is in the background,
> for example while the user switches to an AI chat app to copy a command or paste the output.
> The service is started only when the user opens a session, shows an ongoing notification with the
> number of open sessions and a "Disconnect all" action, and stops as soon as the last session is
> closed. None of the other foreground service types fits a user-initiated, long-lived interactive
> remote shell connection.

## 7. Выпуск

1. «Тестирование → Закрытое тестирование → Создать выпуск», загрузите `dist/clipshell-1.2.aab`.
2. Описание выпуска:
   ```
   <ru-RU>
   Первая версия ClipShell: SSH-клиент для работы с ИИ. Копирование команды с выводом для ИИ-чата, отправка в ИИ через «Поделиться», умная вставка команд из ответов ИИ. Полностью бесплатно, без рекламы.
   </ru-RU>
   ```
3. Добавьте 12+ тестировщиков, отправьте им ссылку на тестирование и подождите 14 дней.
4. «Рабочая версия → Подать заявку на доступ», ответьте на вопросы о тестировании и опубликуйте.

## Обновления

Перед каждым обновлением увеличьте `versionCode` (и `versionName`) в `app/version.properties`,
соберите `./gradlew -p sdkbuild bundleRelease` тем же ключом загрузки и загрузите новый AAB.
Для сборки положите `upload-key.jks` и `upload.properties` (`storeFile`, `storePassword`, `keyAlias`,
`keyPassword`) в `sdkbuild/keystore/`, а bundletool — в `sdkbuild/tools/`.
